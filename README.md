Welcome to **DEVs P2P AI/ML** — an open-source, peer-to-peer roadmap and resource directory designed to take learners and software engineers from foundational math to deploying production Generative AI, LLMs, and MLOps pipelines.

---

## 🌟 Features of the Website

- ⚡ **Futuristic Preloader**: Dynamic neural initialization and status loading animation.
- 🗺️ **Comprehensive 6-Phase Roadmap**:
  - **Phase 1: Foundations & Math** (Linear algebra, multivariable calculus, probability & Python 3.11+)
  - **Phase 2: Data Science & Wrangling** (NumPy, Pandas, Polars, SQL, EDA, Seaborn/Plotly)
  - **Phase 3: Classical Machine Learning** (Supervised/Unsupervised, Scikit-Learn pipelines, XGBoost, SHAP)
  - **Phase 4: Deep Learning & PyTorch** (Backprop from scratch, CNNs, Vision Transformers, NLP & Attention)
  - **Phase 5: Generative AI, LLMs & Multi-Modal** (Transformers, Prompt Engineering, RAG, LoRA fine-tuning, LangGraph Agents)
  - **Phase 6: MLOps & Production Engineering** (FastAPI, Docker, MLflow, vLLM serving, CI/CD, Drift Monitoring)
- 📊 **Interactive Skill Tracker**: Tick off skills as you progress with persistent `localStorage` progress tracking.
- 📚 **Searchable Vetted Resources Directory**: Filter courses, books, repositories, videos, and research papers by level and cost.
- 🛠️ **6 Capstone Portfolio Blueprints**: Complete real-world project specifications with recommended datasets and tech stacks.
- 👥 **Community & Socials Hub**: Instant links to Discord study pods, GitHub repo, LinkedIn, Twitter/X, and YouTube.
- 🤝 **Contribute Modal**: Copyable Markdown issue templates for easy community submissions.

## 🚀 Quickstart & Local Development

### Prerequisites
- [Node.js](https://nodejs.org/) v18+ (tested on Node v24)
- npm v10+

### Clone & Run

```bash
# Clone the repository
git clone https://github.com/Saisrikar20/DEVs-P2P-AI-ML.git
cd DEVs-P2P-AI-ML

# Install dependencies
npm install

# Start local development server with Hot Module Replacement
npm run dev
```

Visit `http://localhost:5173` in your browser.

### Build for Production

```bash
npm run build
```

This compiles TypeScript and generates optimized static assets in the `dist/` directory, ready to deploy to GitHub Pages, Vercel, Netlify, or Cloudflare Pages.

## 🤝 How to Contribute

We welcome contributions from students, researchers, and engineers around the globe!

1. **Fork** the repository
2. Add your favorite resource in [`src/data/resourcesData.ts`](src/data/resourcesData.ts) or suggest an addition in [`src/data/roadmapData.ts`](src/data/roadmapData.ts)
3. Create a branch: `git checkout -b feature/new-resource`
4. Commit your changes: `git commit -m "feat: add resource for LangGraph agents"`
5. Push to the branch: `git push origin feature/new-resource`
6. Open a **Pull Request**
